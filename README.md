# UVM Assembler and Interpreter

Configuration Management — Practical Assignment 3

Variant: 32

## Description

This project implements an assembler and interpreter for an educational virtual machine (UVM).

## Instruction Set

- LOAD_CONST (31) — load a constant into the accumulator.
- READ_MEM (55) — read a value from memory.
- WRITE_MEM (40) — write the accumulator to memory.
- BITWISE_NOT (18) — perform bitwise NOT.

Each instruction occupies 5 bytes.

## Implementation

Python 3

## Project Stages

1. Assembly language and intermediate representation
2. Binary machine code generation
3. Interpreter and memory operations
4. Bitwise NOT operation
5. Vector processing and testing
